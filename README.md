# Life Hotéis Torres – Landing page

Site estático em um único arquivo: `index.html` (HTML, CSS, JavaScript e imagens embutidos).

## Publicar no GitHub Pages
1. Envie `index.html` e `.nojekyll` para a **raiz** do repositório.
2. Em *Settings → Pages*, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. Aguarde 1–2 minutos. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
